Política de Cookies y almacenamiento local

Esta web usa tecnologías de almacenamiento en el dispositivo para garantizar el funcionamiento del servicio.

1. Qué usamos

En esta versión se emplean mecanismos como localStorage y service worker para guardar sesión, preferencias y datos técnicos necesarios para la plataforma.

2. Finalidad

Permitir el acceso a cuentas, mantener estado de navegación y mejorar la experiencia de uso dentro del sitio.

3. Gestión por el usuario

El usuario puede eliminar los datos guardados desde la configuración del navegador, lo que puede afectar al funcionamiento de ciertas funciones del sitio.

4. Actualizaciones

Esta política puede actualizarse para adaptarse a cambios técnicos o normativos.

Para consultas sobre esta política puedes escribir a soporte@todooficios.es.
